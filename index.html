Choose your workflow below to get started. When you upload a dataset or switch datasets in the top bar, you can pick any column from the Target Column Dropdown and let our intelligent detector decide whether it is Classification or Regression (or override it yourself).

Step 1 • Dataset & Target Setup

Upload Dataset & Select Target Column

Upload any custom CSV or inspect the 5 built-in datasets. Select the target column from a dropdown list of all columns and inspect intelligent Classification vs. Regression detection.

  • Populates a live dropdown with every column in your dataset
  • Automatically detects Classification vs. Regression with full reasoning
  • Previews the ~250-row NaN-free clean sample and column statistics
Mode A • Automated Benchmark

Auto Algorithm Selector (Baseline → Ensemble)

Drops NaN rows, randomly samples ~250 clean rows, and progressively tests every algorithm from a Tier-0 Naive Baseline up to Random Forest & Gradient Boosting to find the best performer.

  • Starts from Tier-0 Dummy Baseline & Tier-1 Linear models
  • Evaluates Accuracy, Precision, Recall, F1, MAE, MSE, RMSE & R²
  • Ranks algorithms by K-Fold Cross-Validation & overfitting gap
Mode B • 100% Manual Sandbox

Manual Learning & Hyperparameter Playground

Does NOT auto-select the algorithm. You manually pick one specific algorithm, tune its hyperparameters, toggle individual features on/off, inject noise, and plot 1D validation curves.

  • Select any single algorithm & tune its exact hyperparameters
  • Toggle feature columns, scaling, polynomial terms & NaN imputation
  • Plot 1D Hyperparameter Validation Curves & compare saved runs
Mode C • Guided Academy & API

ML Concepts Lab & 16 FastAPI Endpoints

Explore interactive ML concepts (Bias-Variance Tradeoff, Feature Scaling Sensitivity, L1/L2 Regularization, Stratified CV) with 1-click playground presets and inspect all 16 FastAPI endpoints.

  • 6 guided ML lessons with 1-click 'Load in Manual Playground' presets
  • Interactive documentation table of all 16 REST API endpoints
  • Direct integration with FastAPI Swagger UI (/docs)
